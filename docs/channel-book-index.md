# فهرسة قناة الكتب

البوت ما يكدر يسحب سجل القناة السابق من Bot API، وما عنده وصول لحساب عضو القناة. الفهرس يبقى فارغاً إلى أن يستورد مالك البوت تصدير القناة. ماكو مزامنة تلقائية للرسائل الجديدة بهذي الطريقة.

1. في Telegram Desktop افتح قناة `@lovekotob`، ومن القائمة اختار Export chat history. اختار JSON، ولا تحتاج تنزيل ملفات PDF حتى تفهرس بيانات الرسائل.
2. بعد تنصيب Node.js وتشغيل `npm ci` داخل المستودع، شغّل:
   `node scripts/split-lovekotob-export.mjs path/to/result.json path/to/batches`
3. من حساب مالك البوت، أرسل ملفات `lovekotob-index-*.json` الناتجة للبوت بالخاص. كل ملف يحوي حتى 1000 سجل؛ البوت يرد بعد استيراده. إذا التصدير كبير، عدد الدفعات قد يكون كبيراً ولا تُستورد تلقائياً.
4. دوّر بالعنوان أو المؤلف داخل خدمة الكتب. الفهرس يبحث فقط ضمن الرسائل التي استُوردت وكانت لها بيانات PDF وعنوان يمكن قراءته. إعادة التصدير والاستيراد مطلوبة لإضافة الرسائل الجديدة.

هذه الفهرسة لا تمنح صلاحية للوصول إلى الملف أو نشره. زر النتيجة لا يحوّل رسالة القناة مباشرة: يتحقق من مطابقة العنوان والمؤلف مع سجل كتاب، ثم يبحث عن نسخة إنترنت أرشيف من الملكية العامة. قد لا يلقى تطابقاً أو ملفاً متاحاً. نسخ القناة المحولة سابقاً للبوت لا تُرسل إلا إذا طابقت بصمتها النسخة المتحقّق منها. لا ترسل تصدير محادثاتك الشخصية للبوت.

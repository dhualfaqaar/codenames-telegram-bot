# بوت كود نيمز على تلجرام 🎮

بوت لعبة **Codenames (كود نيمز)** بالعربي لتلجرام — يلعب بالقنوات والمجموعات،
مع وضع **الرسالة الواحدة** (لوحة اللعبة تتنعدّل باستمرار بدل إرسال رسائل جديدة).

## المميزات

- 🕵️ **القائد (الجاسوس)** يكتب التلميح **بالخاص** بلا أي أوامر (كلمة + رقم).
- 📢 **اللعب بالقنوات**: أرسل `/start` للبوت بالخاص ثم شارك اللعبة بقناتك.
- 👥 الأعضاء يخمّنون بالضغط على الأزرار فقط — بلا أوامر.
- 🔄 رسالة لعبة واحدة تتنعدّل باستمرار.

## التشغيل

يحتاج متغير بيئة واحد:

- `TELEGRAM_BOT_TOKEN` = توكن البوت من BotFather.

## خدمات الأفلام والترجمات

تعرّف لقطات الأنمي يستخدم trace.moe، أما التعرّف على الأفلام والمسلسلات فيحتاج سرّ Cloudflare `GEMINI_API_KEY`. البحث عن ملفات الترجمة وإرسالها يحتاج `OPEN_SUBTITLES_API_KEY` من OpenSubtitles؛ أضفهما كـ Worker Secrets (وللتشغيل المحلي في `.env`). لا تضع مفاتيح API في `wrangler.toml` أو في Git.

## متابعة النادي وتنبيهات المباريات

من خدمة **مباريات كرة القدم**، يقدر المستخدم بالخاص يختار نادياً أو منتخباً لمتابعته اختيارياً. يقدر يشغّل أو يوقف تنبيهات الأهداف وبداية المباراة ونهايتها، أو يلغي المتابعة بالكامل؛ اختيار فريق مو شرط لاستخدام البوت أو عرض المباريات. يفحص البوت النتائج كل خمس دقائق، لكن وصول التنبيه يعتمد على ظهور المباراة وتحديث النتيجة في مصادر البيانات المتاحة.

## الألعاب التفاعلية

يفتح زر **🎮 الألعاب التفاعلية** مكتبة ألعاب عربية داخل المتصفح. الشطرنج وأونو والرسم والتخمين وبوكر تكساس تعمل في غرف خاصة مشتركة؛ ينشئ اللاعب غرفة ويرسل رابطها لصديقه، من دون تحويل إلى قناة أو كروب. الشطرنج يبدأ عند انضمام لاعب ثانٍ، وأونو والرسم والبوكر تبدأ بعد ما يضغط أحد اللاعبين زر البدء. البوكر يستخدم رقائق افتراضية فقط ولا يتضمن أموالاً حقيقية. السودوكو تبقى لعبة فردية على `/sudoku`. ألعاب المجموعات الأخرى تظهر كقيد التجهيز داخل المتصفح ولا تحوّل المستخدم إلى محادثة تيليجرام. ملف اللاعب يستخدم صورة البوت ويحمّل إحصائيات البوت بعد التحقق من توقيع Mini App.

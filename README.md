# بوت كود نيمز على تلجرام 🎮

بوت لعبة **Codenames (كود نيمز)** بالعربي لتلجرام — يلعب بالقنوات والمجموعات،
مع وضع **الرسالة الواحدة** (لوحة اللعبة تتنعدّل باستمرار بدل إرسال رسائل جديدة).

## المميزات

- 🕵️ **القائد (الجاسوس)** يكتب التلميح **بالخاص** بلا أي أوامر (كلمة + رقم).
- 📢 **اللعب بالقنوات**: أرسل `/start` للبوت بالخاص ثم شارك اللعبة بقناتك.
- 👥 الأعضاء يخمّنون بالضغط على الأزرار فقط — بلا أوامر.
- 🔄 رسالة لعبة واحدة تتنعدّل باستمرار.

## التشغيل

يحتاج متغير بيئة واحد:

- `TELEGRAM_BOT_TOKEN` = توكن البوت من BotFather.

## خدمات الأفلام والترجمات

تعرّف لقطات الأنمي يستخدم trace.moe، أما التعرّف على الأفلام والمسلسلات فيحتاج سرّ Cloudflare `GEMINI_API_KEY`. البحث عن ملفات الترجمة وإرسالها يحتاج `OPEN_SUBTITLES_API_KEY` من OpenSubtitles؛ أضفهما كـ Worker Secrets (وللتشغيل المحلي في `.env`). لا تضع مفاتيح API في `wrangler.toml` أو في Git.

## متابعة النادي وتنبيهات المباريات

من خدمة **مباريات كرة القدم**، يقدر المستخدم بالخاص يختار نادياً أو منتخباً لمتابعته اختيارياً. يقدر يشغّل أو يوقف تنبيهات الأهداف وبداية المباراة ونهايتها، أو يلغي المتابعة بالكامل؛ اختيار فريق مو شرط لاستخدام البوت أو عرض المباريات. مع وجود متابعة وتنبيه فعّال، يفحص البوت النتائج كل 10 ثوانٍ عبر منبّه Durable Object؛ وصول التنبيه يعتمد أيضاً على وقت تحديث مصدر النتائج.

## الألعاب التفاعلية

يفتح زر **🎮 الألعاب التفاعلية** مكتبة ألعاب عربية داخل المتصفح، وتبقى الدعوات على رابط Code Games بمعاينة تحمل اسم اللعبة وصورة البوت. الشطرنج وأونو والرسم والتخمين وبوكر تكساس تعمل في غرف مشتركة؛ ينشئ اللاعب غرفة خاصة لصديقه، وتظهر تحديثات الانضمام للطرفين تلقائياً. الشطرنج يتيح اللعب ضد بوت محلي بسيط بمستوى ELO تقريبي معلن، أو مطابقة عشوائية قريبة من تصنيف اللاعب، أو دعوة صديق. تصنيف ELO محفوظ على جهاز اللاعب ويتحدث بعد مباريات الشطرنج؛ مستوى البوت ليس ادعاءً بقوة محرك احترافي. السودوكو تتيح اللعب الفردي باختيار المستوى أو سباقاً عشوائياً على اللغز نفسه؛ أول من يحله يفوز. أونو والرسم والبوكر تبدأ بعد ما يضغط أحد اللاعبين زر البدء. البوكر يستخدم رقائق افتراضية فقط ولا يتضمن أموالاً حقيقية. ألعاب المجموعات الأخرى تظهر كقيد التجهيز داخل المتصفح ولا تحوّل المستخدم إلى محادثة تيليجرام. ملف اللاعب يستخدم صورة البوت ويحمّل إحصائيات البوت بعد التحقق من توقيع Mini App.
